## 🚀 Projects

<h3><img src="assets/repup.svg" width="32" height="32" align="absmiddle" alt="" />&nbsp; <a href="https://repup.sk">RepUp</a> — software for gyms</h3>

Gym management that keeps working without internet: checkout with eKasa, memberships, entry control and stock in one panel. A desktop-first admin with offline sync, a REST API, a public website, and a family of mobile apps — for members, staff/POS, personal trainers and a fiscal terminal — plus a native card-reader bridge.
<br>`TypeScript` · `React` · `Zustand` · `Dexie` · `Node.js` · `Express` · `MongoDB` · `Electron` · `Expo` · `Next.js` · `Go`

<h3><img src="assets/mygren.png" width="32" height="32" align="absmiddle" alt="" />&nbsp; Mygren 5.0 — heat pump control app</h3>

Control and monitoring for heat pumps. The React app runs in the browser and as a native iOS/Android app, and talks directly to a lightweight server running on the heating unit itself — with a weekly temperature planner, a protected service-technician mode, licence validation and automatic discovery on the local network.
<br>`React 19` · `React Router 7` · `Tailwind 4` · `Capacitor` · `Express 5` · `SQLite` · `mDNS`

<h3><img src="assets/kvito.svg" width="32" height="32" align="absmiddle" alt="" />&nbsp; Kvito — cloud eKasa fiscalization</h3>

Cloud fiscalization for the Slovak eKasa system in SORP mode: a POS or e-shop sends a sale over a REST API, and Kvito signs the receipt, stores it in a tamper-evident chain, registers it with the Financial Administration and returns the fiscal receipt. *(MVP, not certified.)*
<br>`TypeScript` · `Node.js` · `Zod` · `Docker`

<h3><img src="assets/nocnagabku.svg" width="32" height="32" align="absmiddle" alt="" />&nbsp; <a href="https://nocnagabku.sk">Noc na GAB-ku</a> — event website</h3>

Website for an overnight event for secondary-school students at Gymnázium Antona Bernoláka in Námestovo: talks, workshops and a night film screening.
<br>`React` · `Vite` · `Tailwind` · `Strapi`
